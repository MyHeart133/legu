# Legu 听书(TTS 朗读)功能计划

> 目标:让 Legu 里 300+ 书源搜到的**任何一本书**都能听 —— 实时合成朗读,不依赖现成有声书资源。

---

## 一、最终效果(能做到什么)

1. **任何书都能听**:搜到什么听什么,冷门书/下架书也有"有声版"
2. **三种音色路线**(从省事到讲究):
   - **系统语音**(离线免费):iOS 内置中文语音,飞行模式也能听
   - **微软神经音色**(免费在线,**已实测可用**):晓晓/晓伊/云健/云希/云夏/云扬 6 个普通话 +
     东北话晓北 / 陕西话晓妮 + 粤语 3 个 + 台湾腔 3 个,共 14 个,接近真人
   - **自定义朗读引擎**:兼容「阅读」(Legado)的朗读引擎格式,可导入社区合集;
     自建克隆服务(见第四节)也走这条路 —— **"想用什么声线用什么声线"**
3. **播放体验**:后台播放、锁屏/控制中心控制(上一章/播放/下一章)、语速 0.5–2×、
   定时停止(15/30/60 分钟 / 播完本章)、逐句流水线预合成(不卡顿)、章末自动续播、耳机控制
4. **听读一体**:听到哪、读到哪 —— 复用现有「章内字符偏移」机制,听书↔阅读无缝切换
5. **界面**:阅读页底部新增「听书」按钮 → 迷你播放条;点开**全屏听书页**(大封面/章节/进度/音色/语速/定时)

## 二、架构(4 个模块,思路与书源一致)

| 模块 | 职责 |
|---|---|
| **TTSEngine 协议层** | 朗读引擎抽象:① SystemTTSEngine(AVSpeechSynthesizer,离线)② EdgeTTSEngine(微软免费通道,WebSocket→MP3 流)③ CustomHTTPTTSEngine(Legado 朗读引擎格式:URL 模板 `{{speakText}}`/`{{speakSpeed}}`,GET/POST + JSON body,复用书源的 URL 解析器) |
| **TTSService 调度器** | 断句(按标点切句、限长)→ 合成流水线(播 N 句时预合成 N+1/N+2,整章排队,章末预取下一章)→ 合成缓存(引擎+音色+文本哈希,重听零延迟)→ 切章/切音色时队列重建 |
| **AudioPlayer** | AVAudioSession(.playback)+ 后台音频(Info.plist 加 `UIBackgroundModes: audio`);锁屏信息与远程控制(MPNowPlayingInfoCenter / MPRemoteCommandCenter);断点续播、耳机/来电事件 |
| **听书 UI** | 迷你播放条(阅读页内)+ 全屏听书页 + 朗读引擎管理(内置引擎列表、导入 Legado 朗读引擎 JSON/URL、试听) |

## 三、分阶段实施(每阶段可独立发版)

- **阶段 1(v1.4.0)**:系统语音 + 播放器骨架 + 听书 UI + 后台/锁屏控制
- **阶段 2(v1.5.0)**:微软 14 个免费音色 + 音色选择 + 定时停止 + 预合成流水线
- **阶段 3(v1.6.0)**:自定义朗读引擎(Legado 格式兼容 + 导入 + 试听)+ 听读位置同步
- **阶段 4(按需)**:多音字/数字读音词典、听书历史、锁屏封面、车载模式

## 四、声线问题(直说:能不能用沈腾的?)

- **官方渠道:没有。** Apple/微软/讯飞/火山等所有持证 TTS 平台的音色库都是自有音色或已授权音色,
  不会提供"沈腾的声线";付费的"声音复刻"服务也会要求本人授权证明。
- **技术路线:声音克隆可以做到"很像"。** 开源方案(GPT-SoVITS / CosyVoice / IndexTTS 等)
  用几秒~几分钟目标人音频就能做出音色模型,社区里也流传各种名人音色模型。
  自己在电脑/服务器上跑一个这样的 TTS 服务(它自带 HTTP 接口),用 Legu 的
  「自定义朗读引擎」填一个 URL 就能接进来 —— 这就是"想用什么声线用什么声线"的实现方式。
- **边界(一句话)**:素材自己找、服务自己搭、自己听 = 自己把握;公开传播或商用会触碰
  《民法典》第 1023 条的声音权益(参照肖像权保护),风险自担。App 不做限制,也不提供素材。
- **更省事的替代**:微软"晓晓/云希"已接近真人(试听样音见下);或用 Apple「个人声音」/
  自建克隆做"自己的声音"。

## 六、风险与对策

| 风险 | 对策 |
|---|---|
| 微软通道协议变动 | 自定义引擎兜底;引擎可插拔 |
| iOS 后台长播 | AVAudioSession playback 标准方案(先例充足) |
| 长文本合成延迟 | 流水线预合成 + 缓存;首句优先,边合成边播 |
| 音频版权 | 合成结果仅本机缓存自用,不做导出/分享 |
